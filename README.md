# Saket Gupta | Cybersecurity Portfolio

My personal website for showcasing my cybersecurity experience and projects, and for hosting blog posts and CTF writeups.

**Live site:** https://coders543.github.io/Saket_Gupta.github.io/

---

## About

I'm a Computer Science student at UC Irvine with a strong interest in cybersecurity, systems architecture, and network defense. This site is designed to feel like a Linux terminal, so visitors can explore my work by typing commands or by clicking the dashboard cards.

## Features

- **Ubuntu-style boot sequence** when the page loads
- **Interactive terminal** with working commands
- **Dashboard sections:** whoami, experience, projects, skills, and contact
- **Full-page project views** with overview, what I built, what I learned, and links
- **Experience timeline** covering cybersecurity competitions, awards, and leadership
- **Animated background** with slowly drifting, color-shifting gradients
- **Responsive layout** that works on desktop and mobile
- **Hidden blog area** for future CTF writeups and homelab documentation (see if you can find it)

## Terminal Commands

| Command | Description |
| --- | --- |
| `help` | Show available commands |
| `ls` | List sections |
| `cd [dir]` | Open a section (`whoami`, `projects`, `skills`, `experience`, `contact`) |
| `cat [file]` | Read a section |
| `clear` | Clear the terminal output |
| `restart` | Reboot the system and replay the boot sequence |

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (no frameworks or build step)
- [Ubuntu Mono](https://fonts.google.com/specimen/Ubuntu+Mono) via Google Fonts
- Hosted on GitHub Pages
